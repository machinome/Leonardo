These are unedited renders of the gallery's own machinome models. No
museum images or third-party CAD are included. Run from the repository root:

```sh
machinome snapshot hydraulic_sawmill -o _evidence/sawmill-isometric.png --autocenter --viewall --time 0.065
machinome snapshot hydraulic_sawmill -o _evidence/sawmill-shaft.png --autocenter --viewall --camera 0,0,0,90,0,0,1000 --time 0.125
machinome snapshot automatic_weaving_loom -o _evidence/loom-isometric.png --autocenter --viewall --time 0.25
```

The selected PNGs here were copied from those outputs after inspection.
They accompany [the measured regression record](../consolidation.md).
