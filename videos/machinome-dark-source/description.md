# Machinome — dark source study

A visual experiment for the release film: actual Python imports, assembly
architecture and simulation method on a dark background. Selected excerpts from
models/hydraulic_sawmill/model.py at a01fb865426de9967f690b4a7a1230684eb1e523.
Omission markers stand for code not shown. The closing text reveal is editorial
movement, not a record of the code being written. No machine animation is shown.
