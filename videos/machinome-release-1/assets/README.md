# Film assets

The white mark and wordmark are copied unchanged from the workspace's
`visual-identity/brand/v1/`. They retain that repository's separate artwork
and trademark boundary; the gallery's source licence does not relicense
them. The pilot requested the Machinome logo in this release-film proposal.

Space Grotesk and IBM Plex Mono are copied unchanged from
`visual-identity/assets/fonts/`, with their OFL notices. The stage uses
local embedded fonts, with no runtime font service.

`pronunciation.json` is the existing approved Jessica/ElevenLabs dictionary
record from `machinome-revolutions-v2`. It contains IDs and a pronunciation
rule, not credentials. The film makes no new dictionary and substitutes
no spelling alias into the captions.
