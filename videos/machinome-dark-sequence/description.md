# Machinome — machine, source, machine

A 28-second release-film visual test. The real sawmill moves, the film cuts to
an architectural Python excerpt, and then returns to the moving mechanism.
Dark throughout, never side-by-side. Omission markers identify source not shown;
the final two-line reveal is an editorial effect, not a live coding recording.

Leonardo da Vinci Gallery. Vibecoded by Astra under Luis Henrique Cassis
Fagundes's direction. Copyright (C) 2026 Luis Henrique Cassis Fagundes.
AGPL-3.0-only. AI-written script and synthetic feminine narration using
ElevenLabs Jessica / Eleven v3, reused unchanged. No music. Optional subtitles
are supplied as a separate SRT, not burned into the movie.

The sawmill is an educational geometric/kinematic reconstruction informed by
the Milan museum interpretation of Leonardo's hydraulic saw study. Fluid and
cutting forces are not simulated. The closing view hides the supporting frame
to expose the mechanism. Code comes from the actual project model at revision
a01fb865426de9967f690b4a7a1230684eb1e523. Public source and simulation links remain
pending. Nothing has been uploaded or published.
