# Selected reconstruction evidence

## Full timber pass — 19 September 2026

Inspected original CAD snapshots for the current model:

- [Start](full-pass-start.png): the billet is entirely upstream of the teeth.
- [Mid-cut](cutting-mid-pass.png): the split is open behind the teeth and filled
  by the shrinking molejo insert ahead of them.
- [End, side alignment](full-pass-end.png): the trailing end clears the saw;
  both pairs of rollers remain on the rails.

```sh
machinome snapshot hydraulic_sawmill -o models/hydraulic_sawmill/docs/evidence/full-pass-start.png --autocenter --viewall --time 0 --imgsize 1400x1000
machinome snapshot hydraulic_sawmill -o models/hydraulic_sawmill/docs/evidence/cutting-mid-pass.png --camera=250,-220,850,0,0,410 --time 0.5 --imgsize 1200x900
machinome snapshot hydraulic_sawmill -o models/hydraulic_sawmill/docs/evidence/full-pass-end.png --autocenter --viewall --time 1 --camera 0,0,300,90,0,0,1200 --imgsize 1400x1000
```

## Earlier reconstruction evidence

The images and commands below document the former four-turn model. Its phase
fractions are historical; the current timeline spans 74 turns.

Original CAD renders, inspected on 12 September 2026. These are not museum
photographs. Read the [research record](../reconstruction.md) for provenance
and the [certificate](../validation.md) for geometric evidence and limits.

| Image | What to inspect |
| --- | --- |
| [Museum isometric](museum-isometric.png) | Phase 270°: low undershot channel, open table, two-post sash, carriage and end return pulley |
| [Rear feed alignment](feed-alignment.png) | Phase 210°: lower saw journal, closed tie, long rocker/short arm, driving hook and opposite holding pawl |
| [Undershot drive](undershot-drive.png) | Phase 90°: lower channel, wheel journals, crank/rod alignment and saw-journal slot |

Reproduce from the gallery root with the default OpenSCAD renderer:

```sh
machinome snapshot hydraulic_sawmill -o models/hydraulic_sawmill/docs/evidence/museum-isometric.png --autocenter --viewall --time 0.1875 --imgsize 1400x1000
machinome snapshot hydraulic_sawmill -o models/hydraulic_sawmill/docs/evidence/feed-alignment.png --camera=-90,1200,400,-90,120,340 --time 0.1458333333 --imgsize 1600x1000
machinome snapshot hydraulic_sawmill -o models/hydraulic_sawmill/docs/evidence/undershot-drive.png --camera=160,-1500,250,0,-80,200 --time 0.0625 --imgsize 1400x1100
```

The rear and drive images deliberately frame the transmission, not the full
tower. Whole-machine and browser views supply that context. Browser desktop,
narrow, mechanism and native-control captures are generated by the finite
browser check under ignored `_evidence/hydraulic_sawmill/browser/`.
